# Как устроен раздел «Источник»

Здесь лежит первичный материал. **Ничего из этого не редактируется.** Всё остальное хранилище — производное от этих файлов и должно быть проверяемо по ним.

## Что здесь

| Файл | Что это |
|---|---|
| [[Повесть 1 — полный текст]] | Дословный текст, с. 1–49 оригинала |
| [[Повесть 2 — полный текст]] | Дословный текст, с. 50–170 |
| [[Повесть 3 — полный текст]] | Дословный текст, с. 171–370, включая финал |
| `PDF/` | Исходные PDF без изменений |

## Как это извлекалось

```bash
pdftotext -layout "Приключения во Фрунезко.pdf" frunezko.txt
```

Затем убраны только колонтитулы страниц вида `12 | С т р а н и ц а` и лишние пустые строки. **Больше ничего.** Орфография, пунктуация, опечатки автора, сбитая нумерация глав — всё сохранено.

Чтобы воспроизвести с нуля:

```bash
pdftotext -layout "PDF/Приключения во Фрунезко.pdf" /tmp/raw.txt
python3 - <<'PY'
import re
lines = open('/tmp/raw.txt', encoding='utf-8').read().split('\n')
out = [ln.strip() for ln in lines
       if not re.match(r'^\s*\d+\s*\|\s*(С\s*т\s*р\s*а\s*н\s*и\s*ц\s*а|Страница)\s*$', ln)]
txt = re.sub(r'\n{3,}', '\n\n', '\n'.join(out))
open('/tmp/clean.txt','w',encoding='utf-8').write(txt)
PY
```

Границы повестей в очищенном тексте: 1–899, 900–3364, 3365–7520.

## Как ссылаться на источник

В заметке главы поле `строки-источника` указывает диапазон строк **в файле повести из этой папки**, не в PDF. Проверить факт:

```bash
sed -n '188,233p' "09 Источник/Повесть 1 — полный текст.md"
```

## Нумерация глав в повести 3 сломана

В оригинале две главы под номером 10 («Золото» и «Лешай Синицы»), главы 12 нет вовсе, глава 16 набрана как «16 глава: Тарелка». Это ошибка автора, и она сохранена: в хранилище вторая десятая называется [[П3.10a Лешай Синицы]], между [[П3.11 Не встречай]] и [[П3.13 Сад не для детей]] пропуск. См. [[Противоречия канона]].
